Simulates realistic technical interview environments across multiple job roles and provides bias-resistant feedback.

- Designed a multi-agent evaluation architecture where specialized agents independently assess technical accuracy, communication clarity, and confidence.

- Integrated Ollama (Llama 3) and Gemini API with structured prompt engineering to generate personalized feedback reports.
